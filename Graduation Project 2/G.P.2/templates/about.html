About the Project

Project Title

MedAnalyzer System

Project Idea / Overview

This system allows healthcare providers or users to upload patient data in CSV format, then analyzes key health indicators such as BMI, blood pressure, sugar levels, and more. It automatically detects critical health cases and generates visual graphs and downloadable PDF reports.

Project Goals

  • Analyze health data efficiently
  • Automatically identify critical cases
  • Visualize data in a user-friendly way
  • Generate downloadable health reports

Key Features

  • BMI Calculation
  • Blood Pressure Analysis
  • Blood Sugar Monitoring
  • Temperature & Heart Rate Tracking
  • Smoking Status Analysis
  • Gender & Lifestyle-based statistics
  • Graph generation
  • PDF Report Export

Technologies Used

  • Backend: Python, Pandas, Matplotlib, Seaborn, FPDF, Flask
  • Frontend: HTML, CSS, JavaScript, Chart.js Library, jsPDF Library
  • Data Format: CSV
  • Communication: REST API between frontend and backend

Additional Notes

The system is designed for educational purposes and simulates a simplified version of real patient monitoring tools used in healthcare environments.
